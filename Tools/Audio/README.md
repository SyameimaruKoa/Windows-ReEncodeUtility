# 音声同期・チャンネル抽出ツール

Windows PowerShell 5.1以降、FFmpeg、FFprobeを使用。追加のPythonパッケージは不要。
メインの `re-encode-AIOptimus.ps1` からも呼び出せるほか、2つのコマンドを単独実行できる。

## メインメニューから使う

```powershell
.\start.bat "C:\Videos\capture.mkv"
```

- **SBS左右入替＋音声合成**：メインメニューで「テンプレートから選択」→「PS Camera SBS - 左右交換」。映像のエンコード設定はPSVRと同じHEVC QSV品質25・veryslow。次の音声同期メニューで「波形から自動同期する」または「手動オフセットを指定する」を選び、4ch WAVを指定。完成品は `encoded_output\capture.mkv`。同期未使用の場合も、SBS識別情報（StereoMode）を付与したMKVを出力する。
- **音声合成のみ**：メインメニューから「外部音声同期・マルチトラック合成（映像の再エンコードなし）」を選び、WAVと同期方法を指定。映像をコピーし `capture_stereo_sync.mkv` を出力する。

4ch音声は常にメイン・補助の2音声トラックを生成する。録画時間が食い違っていても動画の時間軸に合わせる。自動同期には動画側の比較用音声が必要じゃ。同期エラーが発生した場合、途中までエンコードした映像は一時フォルダーに残して再試行できる。

### カメラ再接続による途中の音ズレ

**自動同期では既定で再接続補正が有効**じゃ。FFmpegの `freezedetect`（映像が1秒以上停止）と `silencedetect`（映像側の音声が1秒以上実質ゼロ）から再接続候補を検出する。候補の前後それぞれで別録りWAVとの波形照合を行い、**同期位置が実際にずれたと確認できた場合だけ**タイムラインを分割する。別録り録音が一時停止していた部分は無音で補い、再開後の音声を元映像の時刻へ合わせ直す。メイン・補助のOpusトラックには同じ補正を適用する。

画面が静止しているだけ、あるいは単に無音になっただけで音声の同期位置が変わっていなければ分割しない。十分な波形一致が得られない場合は、勝手な推測による再配置を避けて処理を中止する。

映像に比較用の音声トラックが**全く存在しない**場合、映像停止だけを手掛かりに別録り音声の正確な開始位置・再開位置を自動確定することはできぬ。その場合は録画側のタイムコードなど別の同期手掛かりが必要じゃ。

## 1. 4chをメインと補助の2トラックに分離する

```powershell
.\Tools\Audio\Convert-AudioToStereo.ps1 -Input ".\PSCam4Win-mic.wav"
```

4ch音声は既定で **第1トラック（メイン）：ch1→左、ch4→右**、**第2トラック（補助）：ch2→左、ch3→右** に分ける。両者を混ぜず、各チャンネルを独立して保持する。
チャンネル順は音声ストリームの順番であり、マイクの実際の左右配置は実機で確認すること。

別のチャンネルを選ぶ場合:

```powershell
.\Tools\Audio\Convert-AudioToStereo.ps1 -Input ".\recording.wav" -LeftChannel 2 -RightChannel 3
```

4ch入力の既定出力は `*_stereo.mka`（Opus 2トラック、各256kbps VBR）。その他の入力は `*_stereo.opus`（1トラック）。4ch入力では補助トラック保護のためMKAまたはMKVを指定する。元のWAVは変更しない。

## 2. 動画と外部音声を自動同期する

動画には比較用の音声が入っている必要がある。PSCam4Winのモノラル音声などでよい。

```powershell
.\Tools\Audio\Sync-ExternalAudio.ps1 -Video ".\capture.mkv" -Audio ".\PSCam4Win-mic.wav"
```

処理の流れ:

1. 動画内の音声と外部音声を、FFmpegでモノラル音量エンベロープに正規化する。48,028 Hzなどの入力音声は**再生速度を誤って指定し直さず**リサンプリングする。
2. 長さが**短い方**から複数の特徴的な区間を抜き出し、長い方の録音全体を探索する。音声の開始順・長さに依存しない。
3. 映像停止・完全無音を再接続候補として抽出し、候補間の各区間の波形照合から開始オフセットを求める。同期位置の不連続が確実なら区間を分割する。録音クロック差も区間別に補正する。照合不能なら中止する。
4. 4ch入力はch1/ch4をメインの第1トラック、ch2/ch3を補助の第2トラックに変換。メインのチャンネル指定を変更した場合は、残り2chが補助となる。その他の入力は1トラックのみ。
5. **動画の長さ**に合わせる。録画開始前後の余剰音声を切り詰め、不足分に無音を追加する。再接続で欠落した途中の時間も無音で補い、再開後の音声がずれないようにする。
6. 映像をストリームコピーし、同じ時間補正を施したOpus音声2トラック（各256kbps VBR）（4ch入力の場合）と合成してMKVを出力する。メインを既定の再生トラックにする。

出力は `*_stereo_sync.mkv`。元動画と元WAVを維持する。

自動同期できない（動画に比較用音声がない、共通する音がない、極端に短いなど）場合は手動で指定する。

```powershell
.\Tools\Audio\Sync-ExternalAudio.ps1 -Video ".\capture.mkv" -Audio ".\recording.wav" -ManualOffsetSeconds -0.35
```

- 正の値: 外部音声を遅く配置し、先頭に無音を追加。
- 負の値: 外部音声が動画より前に開始したので、その分を前から切り捨てる。
- `-NoDriftCorrection`: 再生速度は変更せず開始オフセットだけを使用。再接続区間の補正は維持。
- `-NoReconnectCorrection`: 再接続候補の検出と区間別補正を無効化し、従来の単一オフセット・時間倍率による同期へ戻す。
- `-KeepReferenceAudio`: 元動画の比較用音声をメイン・補助の後ろ（4ch入力では第3トラック以降）に残す。
- `-LeftChannel` / `-RightChannel`: 使用するチャンネル番号を変更。
- `-FfmpegPath` / `-FfprobePath`: 実行ファイルのパスを指定。
- `-h` / `--help`、または引数なし: 詳しいヘルプ。

## 3. PS CameraのSBS左右交換

テンプレートモードから `PS Camera SBS - 左右交換` を選択する。

- 元のSBSの左右半分を入れ替える。元のフル解像度、縦横比、フレームレートを維持。
- 画質設定は既存PSVRプロファイルと同じ `hevc_qsv -global_quality 25 -preset veryslow`。
- PSVR向けのレンズ補正やクロップは適用しない。
- MKVに `stereo_mode=left_right` を付与する。音声同期未選択では入力音声をコピーし、外部音声を使う場合はメイン・補助のOpus音声2トラックで出力する。

## SBSの3Dメタデータ

PS Camera用とPSVR用SBSプロファイル4種の出力はすべてMKVとし、映像ストリームに `stereo_mode=left_right` を設定する。入力動画の左右を入れ替えるPS Camera用プロファイルは、入れ替え後の並び（左眼→右眼）を宣言する。3D情報の付与自体には再エンコードは不要だが、左右交換・クロップ・レンズ補正を行う既存プロファイルの映像処理には再エンコードが必要。同期ツールだけで再多重化する場合は、元動画のStereoModeを維持する。

## 補足

補助トラックにch2/ch3を残すことで、後からノイズ低減・音源方向推定・ビームフォーミングなどへ活用できる余地がある。元の4ch WAVも保存しておくのがよい。

自動同期は**動画内の参照音声と外部録音に共通する音があること**が条件。実機との組み合わせによって一致率が変わるため、重要な撮影では同期結果と動画終盤の口の動きも確認すること。
